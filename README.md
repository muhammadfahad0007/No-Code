# EV Battery Degradation Case Study

## Project Overview

This project presents a case study on Electric Vehicle (EV) battery degradation, range anxiety, and a proposed user transparency system. It analyzes the factors affecting battery performance and suggests a dashboard that provides users with detailed battery health information.

## Objectives

- Study EV battery degradation.
- Analyze battery health and driving range.
- Understand the causes of range anxiety.
- Propose a transparent battery monitoring system.
- Recommend methods to improve battery lifespan.

## Features

- Battery Health (SOH) Analysis
- Battery Life Cycle Analysis
- Range Prediction
- Temperature Impact Analysis
- Charging Behaviour Analysis
- User Transparency Dashboard
- Battery Degradation Charts
- Comparison of Existing and Proposed Systems

- Charts and Tables
